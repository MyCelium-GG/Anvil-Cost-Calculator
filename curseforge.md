# Anvil Cost Calculator

Know the XP before you pay. Click the XP button on the anvil, pick any enchantable item (or just books), set what it already has and which books to add, and get the cheapest order to apply them with every step's level cost. No keybinds.

![The planner showing the cheapest order for a diamond chestplate, with the level cost of each step](https://wiki.mycelium-gg.org/anvilcostcalculator/img/planner-chestplate.png)

- Works for tools, weapons, armor, flint and steel, elytra and combining books
- Vanilla-exact math: prior work, book discount, level merging and conflicts
- Avoids "Too Expensive!" steps whenever an order exists
- Fills in from the anvil's left slot and locks conflicting enchantments
- Tooltips show anvil uses and the prior work penalty

![The XP button on the anvil screen](https://wiki.mycelium-gg.org/anvilcostcalculator/img/anvil-button.png)

## Install

Client side: install it in your own game.

Requires [Mycel](https://www.curseforge.com/minecraft/mc-mods/mycel): install it alongside this mod. Minecraft 26.1, 26.2 and 26.3 on Fabric, Forge and NeoForge, Java 25. On Fabric you also need Fabric API.

Every setting and command is on the [wiki](https://wiki.mycelium-gg.org/anvilcostcalculator/).
