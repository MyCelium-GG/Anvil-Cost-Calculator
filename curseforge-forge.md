# Anvil Cost Calculator (Forge)

Know the XP before you pay. Click the **XP** button on the anvil, pick any
enchantable item (or just books), set what it already has and which books
to add, and get the cheapest order to apply them with every step's level
cost.

- Every enchantable item, or books only; avoids "Too Expensive!" steps
- Vanilla-exact math; tooltip shows anvil uses and prior work penalty

Requires **Mycel**. Needs Forge 66.0.9+, Minecraft 26.3, Java 25.
